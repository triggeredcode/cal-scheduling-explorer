Model

Exhaustive sees the whole request list. Greedy commits as requests arrive. The first case minimizes squared final load; the second maximizes accepted requests.

HB counts independent complete assignments. Greedy scanning grows as O(BH). The counters use different work units, not measured runtime. This toy model is simpler than Cal.com’s weighted policy.
